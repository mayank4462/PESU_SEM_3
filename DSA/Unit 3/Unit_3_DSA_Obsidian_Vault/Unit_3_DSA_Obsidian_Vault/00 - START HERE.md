## Source coverage

The vault includes all 25 original files from the supplied `U3Codes.zip` (C source files, headers, Makefiles and README). Each project is grouped in its own folder, and key implementations are additionally split into individual code notes.

## Hashing note

The supplied `U3Codes.zip` does **not** contain a Hashing folder or hashing source files. Therefore, no hashing code notes have been invented or added. To include the four hashing implementations, their source files need to be supplied in a separate archive.
