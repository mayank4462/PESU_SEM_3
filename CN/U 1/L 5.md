# 1. Internet Delay — `traceroute`

## What does "real" Internet delay look like?

The lecture introduces **`traceroute`**, a program used to measure the delay from a source host to routers along the end-to-end path toward a destination.

### Traceroute provides:

- Delay measurements from the **source to routers along the path**.
- It sends **three packets** that will reach a particular destination with a specific **time-to-live (TTL)** value.
- The router sends a **return packet** to the sender.
- The sender measures the **time interval between transmission and reply**.

### Basic idea

```
Source → Router 1 → Router 2 → Router 3 → Destination
           ↓          ↓          ↓
         delay      delay      delay
```

The delay shown by traceroute is generally the **round-trip time (RTT)** between the source and the router.

---

# 2. How Does Traceroute Work?

The lecture diagram shows packets being sent with progressively increasing TTL values.

For example:

```
Source
   |
   | TTL = 1
   ↓
Router 1
   |
   | TTL = 2
   ↓
Router 2
   |
   | TTL = 3
   ↓
Router 3
   |
   ↓
Destination
```

When the TTL expires at a router, that router sends a response back to the source.

The source records how long it took to receive the response.

### Important

The lecture explicitly notes:

> **Traceroute is not completely trustworthy.**

So traceroute measurements should be interpreted carefully.

---

# 3. Understanding a Traceroute Output

The example on page 4 shows multiple routers and **three delay measurements** for each hop.

Example structure:

```
1    Router A       1 ms    2 ms    3 ms
2    Router B       8 ms    11 ms   10 ms
3    Router C       18 ms   22 ms   22 ms
...
```

Each row represents a **hop/router**.

The three values represent multiple measurements of delay to that router.

### Exam point

If asked:

**What does traceroute measure?**

Answer:

> Traceroute measures the delay from the source to each router along the path toward the destination by sending packets with different TTL values and measuring the time between transmission and the router's response.

# 4. Packet Loss

## What is packet loss?

Packet loss occurs when a packet is transmitted but **does not successfully reach its destination**.

The lecture explains packet loss using the concept of a **queue/buffer** at a router.

### Router buffer

A router has a finite-sized buffer:

```
Incoming packets
       ↓
+----------------+
|    BUFFER      |
| [P][P][P][P]   |
+----------------+
       ↓
Outgoing link
```

If packets arrive faster than the router can transmit them, they wait in the buffer.

---

# 5. Why Does Packet Loss Occur?

Suppose:

```
Packet transmission rate > outgoing link capacity
```

Packets start accumulating in the queue.

Eventually:

```
Buffer becomes FULL
        ↓
New packet arrives
        ↓
No space available
        ↓
Packet is DROPPED
```

Therefore:

> **Packet loss occurs when a packet arrives at a router whose buffer is already full.**

### Very important MCQ

**Packet loss occurs primarily when:**

A. CPU is idle  
B. Buffer is full  
C. TTL is large  
D. Bandwidth is zero

**Answer: B. Buffer is full**

# 6. Throughput

## Definition

**Throughput** is the rate at which bits are actually being transmitted from the sender to the receiver.

The lecture defines throughput as:

> **Rate (bits/time unit) at which bits are being sent from sender to receiver.**

Usually measured in:

- bits/sec
- Mbps
- Gbps

---

# 7. Types of Throughput

The lecture distinguishes between **instantaneous** and **average** throughput.

## Instantaneous throughput

Rate measured at a **given point in time**.

```
Instantaneous throughput
= bits transmitted / small time interval
```

It can change continuously depending on network conditions.

---

## Average throughput

Rate measured over a **longer period of time**.

```
Average throughput
= total bits transmitted / total time
```

### Exam difference

|Instantaneous|Average|
|---|---|
|Measured at a particular point/time interval|Measured over a longer period|
|Can vary rapidly|Gives overall performance|
|Short-term rate|Long-term rate|

---

# 8. Throughput Between Two Links

The lecture considers a sender communicating with a receiver through two links.

Suppose:

- First link rate = `Rs`
- Second link rate = `Rc`

If:

```
Rs < Rc
```

then:

```
Throughput = Rs
```

If:

```
Rs > Rc
```

then:

```
Throughput = Rc
```

Therefore:

# `Throughput = min(Rs, Rc)`

The slowest link determines the end-to-end throughput.

---

# 9. Bottleneck Link

The **bottleneck link** is the link on an end-to-end path that has the **lowest transmission rate** and therefore constrains the throughput.

Example:

```
Sender
  |
  | Rs = 10 Mbps
  ↓
Router
  |
  | R = 2 Mbps
  ↓
Router
  |
  | Rc = 8 Mbps
  ↓
Receiver
```

Therefore:

```
Throughput = min(10, 2, 8)
           = 2 Mbps
```

So the middle `2 Mbps` link is the **bottleneck link**.

### Golden rule

> **End-to-end throughput is constrained by the bottleneck link.**

---

# 10. Throughput Numerical Example

Page 10 gives a network scenario involving **10 connections sharing a bottleneck link**.

The lecture states:

- Server transmission rate: `Rs = 2 Mbps`
- Access/link rate: `Rc = 5 Mbps`
- There are **10 clients/downloads**
- The bottleneck link is shared fairly.

The end-to-end throughput for each download becomes approximately:

```
2 Mbps / 10
= 0.2 Mbps
= 200 kbps
```

So:

> **Each download gets approximately 200 kbps.**

This is an important numerical concept.

# 11. Throughput Numerical Example — MP3

Page 9 gives another numerical example.

### Given

MP3 file size:

```
F = 32 million bits
```

Server transmission rate:

```
Rs = 2 Mbps
```

Access link rate:

```
Rc = 1 Mbps
```

The end-to-end transfer rate is:

```
Transfer Rate = min(Rs, Rc)
```

Therefore:

```
= min(2 Mbps, 1 Mbps)
= 1 Mbps
```

Now:

```
Time = File Size / Transfer Rate
```

```
= 32 × 10⁶ / 1 × 10⁶
= 32 seconds
```

### Final answer

# `Time = 32 seconds`

### Exam shortcut

Whenever you're given multiple link rates:

```
Throughput = minimum link rate
```

Then:

```
Time = File size / Throughput
```

# 13. Must-Know Concepts

### Traceroute

Used to measure delays to routers along the path to a destination.

### TTL

**Time To Live** — used by traceroute to cause packets to expire at successive routers.

### RTT

**Round-Trip Time** — time for a packet to travel to a destination/router and for the response to return.

### Packet loss

Packet is dropped when there is no space in the router's buffer.

### Buffer

Temporary storage where packets wait before transmission.

### Throughput

Actual rate at which bits are delivered from sender to receiver.

### Bottleneck link

The slowest link that limits end-to-end throughput.

**Answer:**  
Packet loss occurs when transmitted packets are dropped before reaching the destination. It can occur when a router's buffer becomes full and cannot accommodate an arriving packet.

**Answer:**

**Answer:**

- **Average throughput:** Rate measured over a longer period of time.

A router buffer temporarily stores packets that are waiting to be transmitted through an outgoing link.

# 📝 4-Mark Questions

## 1. Explain how traceroute works.

**Answer:**

1. Traceroute sends packets toward the destination.
2. The packets are assigned progressively increasing TTL values.
3. When the TTL expires at a router, the router sends a response to the source.
4. The source measures the time between sending the packet and receiving the response.
5. Repeating this process reveals the routers along the path and their delays.

**Diagram:**

```
Source → R1 → R2 → R3 → Destination
          ↑    ↑    ↑
        TTL1 TTL2 TTL3
```

---

## 2. Explain packet loss using router buffers.

**Answer:**

A router has a finite buffer to temporarily store packets waiting for transmission. When packets arrive faster than the outgoing link can transmit them, packets accumulate in the buffer. If the buffer becomes completely full, a newly arriving packet cannot be stored and is therefore dropped. This results in packet loss.

```
Packets → [ BUFFER FULL ] → Outgoing link
                ↑
          New packet dropped
```

---

## 3. Explain throughput and bottleneck link.

**Answer:**

Throughput is the rate at which bits are transferred from a sender to a receiver. When data passes through multiple links, the slowest link limits the overall transmission rate. This slowest link is called the bottleneck link.

Throughput=min⁡(R1,R2,…,Rn)Throughput = \min(R_1,R_2,\ldots,R_n)

Example:

```
10 Mbps → 2 Mbps → 8 Mbps
```

Therefore:

Throughput=2MbpsThroughput = 2 Mbps

The `2 Mbps` link is the bottleneck.

---

## 4. Explain instantaneous and average throughput.

**Answer:**

**Instantaneous throughput** is the transmission rate measured at a particular point in time. It can vary rapidly according to network conditions.

**Average throughput** is calculated over a longer period and represents the overall rate of data transfer.

Average Throughput=Total bits transferredTotal timeAverage\ Throughput = \frac{Total\ bits\ transferred}{Total\ time}
