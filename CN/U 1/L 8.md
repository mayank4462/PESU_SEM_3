# 1. The Four Important Types of Delay

A packet travelling through a network can experience four major delays:

```
Total nodal delay
=
Processing delay
+
Queuing delay
+
Transmission delay
+
Propagation delay
```

For this lecture, the major focus is on:

- **Transmission delay**
- **Propagation delay**
- **Queuing delay**
- **End-to-end delay**

---

# 2. Transmission Delay

## Definition

**Transmission delay** is the time required to push all the bits of a packet onto the transmission link.

Formula:

dtrans=LR\boxed{d_{trans}=\frac{L}{R}}

Where:

- `L` = packet length in **bits**
- `R` = transmission rate in **bits/sec**

### Example

Packet size:

L=8000 bitsL=8000\ bits

Link rate:

R=1Mbps=106 bits/secR=1Mbps=10^6\ bits/sec

Therefore:

dtrans=8000106d_{trans}=\frac{8000}{10^6} =0.008s=\boxed{0.008s} =8ms=\boxed{8ms}

This is the one-hop transmission-delay example used in the lecture.

---

# 3. Propagation Delay

## Definition

**Propagation delay** is the time required for a bit to physically travel from one end of the link to the other.

Formula:

dprop=ds\boxed{d_{prop}=\frac{d}{s}}

Where:

- `d` = physical distance of link
- `s` = propagation speed

The lecture uses:

s=3×108 m/ss=3\times10^8\ m/s

for its examples.

---

# 4. Transmission vs Propagation Delay

This is a **very important MCQ concept**.

### Transmission delay

Depends on:

- Packet size `L`
- Transmission rate `R`

dtrans=LRd_{trans}=\frac LR

### Propagation delay

Depends on:

- Distance `d`
- Propagation speed `s`

dprop=dsd_{prop}=\frac ds

### Quick memory

> **Transmission = putting bits onto the wire**

> **Propagation = bits travelling along the wire**

---

# 5. Does Packet Size Affect Propagation Delay?

**No.**

Propagation delay depends on:

distancepropagation speed\frac{distance}{propagation\ speed}

It does **not directly depend on packet size**.

However, transmission delay does depend on packet size:

dtrans=LRd_{trans}=\frac LR

### MCQ trap

**Increasing packet size increases:**

A. Propagation delay only  
B. Transmission delay  
C. Propagation speed  
D. Distance

**Answer: B**

# 6. Does Distance Affect Transmission Delay?

**No, not directly.**

Transmission delay is:

LR\frac LR

So it depends on:

- Packet length
- Transmission rate

Distance affects **propagation delay**.

# 11. End-to-End Delay

If a packet passes through multiple links:

```
Source
  ↓
Link 1
  ↓
Router
  ↓
Link 2
  ↓
Router
  ↓
Link 3
  ↓
Destination
```

Total end-to-end delay is the sum of the delays on each link.

For transmission + propagation:

dend−end=∑(dtrans,i+dprop,i)\boxed{ d_{end-end} = \sum(d_{trans,i}+d_{prop,i}) }

If processing and queuing delays are included:

dend−end=∑(dproc,i+dqueue,i+dtrans,i+dprop,i)\boxed{ d_{end-end} = \sum(d_{proc,i}+d_{queue,i}+d_{trans,i}+d_{prop,i}) }

# 13. Queuing Delay

Now comes one of the **most important topics in this PDF**.

## Definition

**Queuing delay** is the time a packet spends **waiting in the router's buffer before transmission**.

```
Packets arriving
       ↓
+----------------+
|    QUEUE       |
| P P P P P      |
+----------------+
       ↓
Outgoing link
```

If many packets arrive at once, they must wait.

---

# 14. What Causes Queuing Delay?

Suppose:

```
Arrival rate > Service rate
```

Then:

```
Packets accumulate
       ↓
Queue grows
       ↓
Queuing delay increases
```

If the arrival rate is consistently greater than the service capacity, the queue can eventually overflow and cause **packet loss**.

---

# 15. Traffic Intensity

The lecture uses **traffic intensity** to study queuing delay.

Formula:

LaR\boxed{\frac{La}{R}}

Where:

- `L` = packet length in bits
- `a` = average packet arrival rate in packets/sec
- `R` = transmission rate in bits/sec

This is also written as:

LaR\boxed{\frac{La}{R}}

---

# 16. Meaning of Traffic Intensity

### If:

LaR≪1\frac{La}{R}\ll1

Queueing delay is generally small.

### If:

LaR→1\frac{La}{R}\rightarrow1

Queueing delay becomes very large.

### If:

LaR>1\frac{La}{R}>1

The incoming traffic exceeds the link's capacity, so the queue cannot remain stable indefinitely.

The lecture explicitly notes the condition:

LaR<1\boxed{\frac{La}{R}<1}

for the queueing-delay formula.

---

# 17. Queueing Delay Formula

The lecture uses the approximation:

dqueue=La/R1−La/R×LR\boxed{ d_{queue} = \frac{La/R}{1-La/R} \times\frac LR }

Equivalently:

dqueue=LaR−La×LR\boxed{ d_{queue} = \frac{La}{R-La} \times\frac LR }

### Important

The exact presentation in the lecture should be followed for your exam.

The major idea is:

> **As traffic intensity approaches 1, queuing delay increases dramatically.**

The graph on the lecture slide shows this sharp increase.

# 23. Link Utilization

The lecture also asks about **link utilization**.

If a link has capacity `R` and carries traffic at rate `r`:

Utilization=rR\boxed{ Utilization=\frac rR }

### Example

If:

```
Link capacity = 50 Mbps
Actual traffic = 50 Mbps
```

Then:

Utilization=5050=1Utilization=\frac{50}{50}=1 =100%=\boxed{100\%}

If a shared 300 Mbps bottleneck carries 200 Mbps:

Utilization=200300Utilization=\frac{200}{300} =0.67=\boxed{0.67}

or approximately:

67%\boxed{67\%}

# 📝 4-Mark Questions

## 1. Explain transmission and propagation delay with formulas.

**Transmission delay** is the time needed to transmit all packet bits onto the link:

dtrans=LRd_{trans}=\frac LR

where `L` is packet length and `R` is transmission rate.

**Propagation delay** is the time required for the signal to travel across the link:

dprop=dsd_{prop}=\frac ds

where `d` is distance and `s` is propagation speed.

### Key difference:

```
Transmission → depends on L and R
Propagation   → depends on d and s
```

---

# 2. Explain queuing delay and traffic intensity.

Queuing delay is the time a packet waits in a router buffer before transmission.

Traffic intensity is:

ρ=LaR\rho=\frac{La}{R}

where:

- `L` = packet length
- `a` = packet arrival rate
- `R` = transmission rate

For a stable queue:

ρ<1\rho<1

As:

ρ→1\rho\rightarrow1

queuing delay increases significantly. If incoming traffic exceeds capacity, the queue can overflow and packets may be dropped.

---

# 3. Explain end-to-end delay.

End-to-end delay is the total delay experienced by a packet while travelling from source to destination.

It includes:

- Processing delay
- Queuing delay
- Transmission delay
- Propagation delay

Therefore:

dend−end=∑(dproc+dqueue+dtrans+dprop)d_{end-end} = \sum (d_{proc}+d_{queue}+d_{trans}+d_{prop})

For a multi-link problem, calculate the four components at each router/link and add them.

---

# 4. Explain the effect of a bottleneck link on throughput.

The end-to-end throughput is limited by the smallest-capacity link.

For multiple links:

Throughput=min⁡(R1,R2,…,Rn)Throughput=\min(R_1,R_2,\ldots,R_n)

If multiple connections share the bottleneck fairly:

Throughputconnection=RbottleneckNThroughput_{connection} = \frac{R_{bottleneck}}N

The resulting throughput must also be compared with the source and client access-link capacities.
