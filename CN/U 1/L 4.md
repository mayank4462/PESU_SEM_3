# PART 1 — MUST KNOW

# 1. Why Do Packet Delay and Loss Occur?

At a router, packets may have to wait before they can be transmitted.

The main reason is:

> **Packets queue in router buffers.**

If the **arrival rate temporarily exceeds the output link capacity**, packets have to wait.

If the buffer becomes full:

> **Packets are dropped → packet loss.**

### Basic chain

```
Packets arrive
      ↓
Arrival rate > output rate
      ↓
Packets wait in buffer
      ↓
Queueing delay
      ↓
Buffer becomes full
      ↓
Packet loss
```

This is shown on **page 3**.

# 3. Processing Delay

Processing delay is the time required by the router to process the packet.

It includes:

- Checking for bit errors
- Determining the output link

### Typical magnitude

The slide says:

> **Typically microseconds**

### Formula

There is no major formula for processing delay in this lecture.

### Remember

```
Processing delay
= Check packet
+ Determine output link
```

---

# 4. Queueing Delay

Queueing delay is:

> **The time a packet waits in the output link's queue before transmission.**

It depends on:

- How much traffic is arriving
- How quickly the output link can transmit
- Current congestion level

### Important property

Unlike processing, transmission and propagation delay:

> **Queueing delay can vary significantly from packet to packet.**

It can also become very large when congestion is high.

---

# 5. Transmission Delay

Transmission delay is the time required to **push all the packet's bits onto the link**.

Formula:

dtrans=LR\boxed{d_{trans}=\frac{L}{R}}

where:

- LL = packet length in bits
- RR = transmission rate in bits/sec

### Important

Transmission delay depends on:

- Packet length
- Transmission rate

It does **not** depend on the physical distance between routers.

---

# 6. Propagation Delay

Propagation delay is:

> **The time required for a bit to propagate from one router to the next.**

Formula:

dprop=ds\boxed{d_{prop}=\frac{d}{s}}

where:

- dd = physical length of the link
- ss = propagation speed

The slide gives approximately:

s≈2×108 m/secs \approx 2\times10^8\ m/sec

### Important

Propagation delay depends on:

- Distance between routers
- Propagation speed

It does **not** depend on:

- Packet size
- Transmission rate

---

# 7. Transmission vs Propagation Delay

This is a **very high-probability 2/4-mark question**.

|Transmission Delay|Propagation Delay|
|---|---|
|Time to push packet onto link|Time for bit to travel across link|
|dtrans=L/Rd_{trans}=L/R|dprop=d/sd_{prop}=d/s|
|Depends on packet length|Depends on physical distance|
|Depends on transmission rate|Depends on propagation speed|
|Nothing to do with distance|Nothing to do with packet length or transmission rate|

### Easy memory:

> **Transmission = PUSH**

> **Propagation = TRAVEL**

Think:

```
Transmission:
[Router] ========> [Link]
       PUSH bits

Propagation:
[Router] ========> [Router]
       bits TRAVEL
```
