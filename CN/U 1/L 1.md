# PART 1 — MUST KNOW BEFORE THE EXAM

## 1. What is a Computer Network?

A **computer network** is formed when **two or more devices are connected together**.

The devices can:

- Communicate with each other
- Share data
- Share resources

### Example

```
PC ───┐
PC ───┤
PC ───┼── Switch ── Router ── Internet
PC ───┤
Phone ┘
```

# 2. What is the Internet?

### Definition

> **The Internet is an immense network of networks that interconnects billions of computing devices throughout the world.**

Important phrase:

**Internet = Network of Networks**

Do NOT say that the Internet is just "one big network."

It consists of many interconnected networks.

# 5. Packet Switches

Data travels through the Internet in the form of **packets**.

### Packet

A **packet** is a chunk of data.

### Packet switch

A device that forwards packets through the network.

Examples:

- **Router**
- **Switch**

```
Host
  |
  | Packet
  ↓
Router
  |
  | Packet
```

# 8. Protocols

This is one of the **most important topics** from these pages.

## What is a protocol?

A **protocol** is a set of rules governing communication between network entities.

Protocols define:

1. **Format of messages**
2. **Order of messages**
3. **Actions taken when messages are sent**
4. **Actions taken when messages are received**

### Memorize this:

> **Protocol = Format + Order + Actions**

More formally:

> Protocols define the format and order of messages sent and received among network entities, and the actions taken on message transmission and/or receipt.

# 12. Programming Interface

The Internet infrastructure provides a **programming interface** for distributed applications.

It allows applications to:

- "Hook" into the Internet
- Send messages
- Receive messages
- Use Internet transport services

The slides compare this with a **postal service**.

### Easy way to remember

```
Application
     ↓
Programming Interface
     ↓
Internet Infrastructure
     ↓
Network
```

The application uses networking services rather than directly controlling every part of the underlying network.

# 13. Human Protocol vs Network Protocol

The slides use human communication to explain protocols.

Example:

```
Person A: Hi
Person B: Hi
Person A: Got the time?
Person B: 2:00
```

This interaction follows rules:

- What message is sent?
- In what order?
- What response should occur?
- What action follows the response?

Computer communication works similarly, except computers use **formal network protocols**
