# 2. Repeater

## Definition

A **repeater** is a physical-layer device that **regenerates a signal** before it becomes too weak.

### Why do we need it?

As a signal travels through a network:

```
Strong signal → → → Weak signal
```

Eventually the signal becomes too weak.

A repeater:

```
Weak signal
     ↓
  Repeater
     ↓
Regenerated
strong signal
```

### Main functions

1. **Reception** — captures incoming data signals.
2. **Amplification** — strengthens weakened signals.
3. **Regeneration** — reconstructs the signal to ensure integrity.
4. **Transmission** — sends the regenerated signal onward.

### Layer

# Physical Layer

### Important

A repeater **does not understand MAC addresses or IP addresses**.

It simply regenerates the signal.

# 3. Hub

A **hub** is a basic networking device used to connect multiple devices. It broadcasts incoming data to **all connected devices**.

### Layer

# Physical Layer

### Example

Suppose:

```
       PC1
        |
PC2 — HUB — PC3
        |
       PC4
```

If PC1 sends data:

```
PC1 → HUB → PC2
          → PC3
          → PC4
```

The hub sends the data to **everyone**.

---

# 4. Features of a Hub

According to the lecture:

### 1. Broadcast

Always broadcasts data regardless of intended recipient.

### 2. Half-duplex

Only one device can transmit at a time.

### 3. No MAC intelligence

A hub cannot store MAC addresses or maintain MAC address tables.

### 4. No data filtering

It sends data to all connected devices.

### 5. Collision domain

All devices connected to a hub share **one collision domain**.

---

# 5. Modem

A **modem** connects a computer/network to the Internet by converting digital signals into analog signals and vice versa.

The word modem comes from:

> **MO**dulator + **DEM**odulator

---

## Modulation

Digital data:

```
Digital → Analog
```

This is performed when transmitting over an analog communication medium.

## Demodulation

```
Analog → Digital
```

This happens when receiving.

### Full process

```
Computer
Digital data
     ↓
 Modulation
     ↓
Analog signal
     ↓
Internet/communication medium
     ↓
Demodulation
     ↓
Digital data
     ↓
Computer
```

### Layer

# Physical Layer

---

# 6. Bridge

A **bridge** is a Layer 2 device that connects two or more network segments and forwards data based on **MAC addresses**.

### Layer

# Data Link Layer

### Main functions

According to the slide:

1. **Segmentation** — divides a large network into smaller segments to reduce congestion and improve performance.
2. **Filtering** — uses MAC addresses to selectively forward packets.
3. **Learning** — tracks MAC addresses and port mappings.
4. **Forwarding** — directs packets between segments to the intended destination.

---

# 7. Switch

A **switch** is an intelligent Layer 2 networking device that forwards packets/data to the appropriate destination port using MAC addresses.

### Layer

# Data Link Layer

### Example

```
          PC1
           |
PC2 —— SWITCH —— PC3
           |
          PC4
```

If PC1 wants to communicate with PC3:

```
PC1 → Switch → PC3
```

The switch sends the data **only to the appropriate port** rather than broadcasting it everywhere.

---

# 8. Features of Switch

The lecture lists these features:

### 1. Packet switching

Receives and forwards data from source to destination.

### 2. Error checking

Can perform error checking before forwarding.

### 3. Full-duplex

Can operate in full-duplex mode, enabling simultaneous transmission and reception.

### 4. MAC address table

Stores MAC addresses of connected devices.

### 5. Communication

Directs communication only toward the intended destination.

---

# 9. NIC — Network Interface Card

A **NIC** is a physical card/chip that contains a **MAC address** and helps identify a device on a network.

### Layer

# Data Link Layer

### Types

- Wired NIC
- Wireless NIC

---

## Functions of NIC

The lecture lists:

### 1. Connectivity

Links a device to the network through wired or wireless communication.

### 2. Data transmission

Sends and receives data between devices.

### 3. Data conversion

Converts data into appropriate formats for transmission.

### 4. Error handling

Detects and corrects transmission errors.

### 5. Traffic management

Prioritizes or limits data to avoid congestion.

### 6. Security

Provides encryption and authentication.

# 10. Router

A **router** is a network-layer device that forwards packets based on their **IP addresses**.

### Layer

# Network Layer

### Main job

Connect different networks.

```
Network A
   |
 Router
   |
Network B
```

---

# 11. Functions of a Router

## 1. Forwarding

The router:

- Receives packets
- Checks headers
- Performs basic processing
- Forwards packets to the appropriate output port

## 2. Routing

Determines the **best path** for a packet to reach its destination.

It uses routing tables/algorithms.

## 3. NAT

**Network Address Translation (NAT)** translates between:

```
Private IP ↔ Public IP
```

This allows devices using private addresses to access the Internet.

These functions are shown in the lecture on pages 9–10.

---

# 12. Routing vs Forwarding

This is a **very common MCQ trap**.

### Routing

> Determines **which path** the packet should take.

### Forwarding

> Moves the packet to the appropriate **output port**.

Think:

```
Routing = Where should I go?

Forwarding = Send it there.
```

---

# 13. Gateway

A **gateway** is a connectivity device that connects networks with different configurations and acts as a portal between them.

The lecture notes that a gateway can operate at **any OSI model layer**.

### Main idea

```
Network A
   ↓
Gateway
   ↓
Network B
```

It allows communication between networks that may use different protocols or configurations.

---

# 14. Types of Gateway

The lecture identifies two types:

### 1. Unidirectional Gateway

Data flows in **one direction**.

```
A → Gateway → B
```

Changes are replicated in one direction only.

### 2. Bidirectional Gateway

Data flows in **both directions**.

```
A ↔ Gateway ↔ B
```

Used for synchronization between both sides.

---

# 15. Firewall

A firewall is a **network security device** that monitors incoming and outgoing network traffic and allows or blocks traffic according to defined security rules.

### Main purpose

# Security

Example:

```
Internet
   ↓
Firewall
   ↓
Internal Network
```

The firewall decides whether traffic should be allowed or blocked.

### Important

The lecture states that a firewall can be used in:

- Transport layer
- Application layer

# 17. Wireless LAN Controller — WLC

A **Wireless LAN Controller (WLC)** centrally manages multiple APs across an office or campus.

According to the slide:

> WLC centrally manages many APs across an office or campus and handles wireless management and planning.

Think:

```
             WLC
           /  |  \
          /   |   \
        AP1  AP2  AP3
```

Instead of individually managing every AP, the WLC manages them centrally.

# 18. Layer 3 Switch

- Layer 2 switching

# 📝 4-Mark Questions

## 1. Explain the working of a repeater.

**Answer:**

A repeater operates at the Physical Layer. As a signal travels through a network, it becomes weaker due to attenuation and interference. The repeater receives the weakened signal, strengthens/regenerates it and retransmits it toward the destination.

```
Strong signal
      ↓
Weak signal → REPEATER → Regenerated signal
```

Its main functions are reception, amplification, regeneration and transmission.

---

# 2. Explain the working and features of a hub.

**Answer:**

A hub is a Physical Layer device used to connect multiple devices. When a hub receives data, it broadcasts the data to all connected devices.

Features:

1. Operates at Physical Layer.
2. Broadcasts data to all connected devices.
3. Works in half-duplex mode.
4. Has no MAC address intelligence.
5. Does not filter data.
6. All connected devices share a collision domain.

---

# 3. Explain a switch and its features.

**Answer:**

A switch is an intelligent Data Link Layer device that uses MAC addresses to forward data to the appropriate destination port.

Features:

1. Operates at Data Link Layer.
2. Maintains MAC address information.
3. Performs selective forwarding.
4. Can perform error checking.
5. Supports full-duplex communication.
6. Reduces unnecessary traffic compared with a hub.

---

# 4. Explain the functions of a router.

**Answer:**

A router operates at the Network Layer and connects different networks.

Its major functions are:

1. **Forwarding:** Receives packets, checks headers and sends them to the appropriate output port.
2. **Routing:** Determines the best path for a packet to reach its destination.
3. **NAT:** Translates private IP addresses to public IP addresses and vice versa.

# 8. Explain firewall.

**Answer:**

A firewall is a network security device that monitors incoming and outgoing traffic.

It:

1. Inspects network traffic.
2. Applies predefined security rules.
3. Allows legitimate traffic.
4. Blocks unwanted or unauthorized traffic.
5. Can operate at transport or application layer.

Combines Layer 2 switching and Layer 3 routing and is used in campus/data-center networks.
